## 해결하려는 문제

API 요청에서 작업 상태, 실행기, 로그까지 이어지는 인프라 오케스트레이션 프로젝트입니다. 공개 코드의 책임 분리와 테스트 지점을 중심으로 소개합니다.

## 코드와 검증

[코드 탐색·실행 가이드](https://github.com/swlee3306/infra-orch-studio/blob/main/docs/PORTFOLIO.md)에서 구현 범위, 실행 명령과 검증 한계를 확인할 수 있습니다. 빌드나 합성 입력 테스트 성공을 실제 운영 안정성 또는 성능 수치로 확대하지 않습니다.
