Go를 중심으로 클라우드 인프라의 데이터를 수집하고, 반복되는 운영 작업을 자동화하는 개발자 이상욱입니다.

문제가 생겼을 때 원인을 추적할 수 있고, 같은 조건에서 다시 검증할 수 있는 도구를 만드는 데 관심이 있습니다. OpenStack·Kubernetes 환경을 다루며 쌓은 문제의식은 개인 프로젝트에서도 상태 관리, 오류 처리, 관측성, 테스트로 이어집니다.

## 공개 프로젝트에서 확인할 수 있는 것

- **infra-orch-studio**: 인프라 작업을 API·상태·실행기·로그로 연결하는 구조.
- **network-collector**: OpenStack 네트워크 데이터를 수집하고 API와 화면으로 연결하는 구조.
- **gitlab-mr-review-automation**: MR 중복 처리, 변경된 커밋 감지, 재시도와 입력 보호. 실제 GitLab 연결은 읽기 전용이며 자동 댓글이나 외부 AI 전송은 하지 않습니다.
- **gitops-deployment-guardrails**: 렌더링된 Kubernetes JSON 정책 검사와 배포 전 변경 계획. 클러스터에 적용하지 않습니다.

## 일하는 방식

기능을 많이 나열하는 것보다 동작 범위와 실패 조건을 명확히 설명하려고 합니다. 실험적인 코드와 운영에서 검증한 경험을 구분하고, 공개 저장소에는 확인 가능한 실행 방법과 제약을 함께 적습니다.

회사 내부 코드·설정·고객 정보를 공개 프로젝트의 증거로 사용하지 않습니다. 상세 경력과 이력서는 별도로 제공합니다.
